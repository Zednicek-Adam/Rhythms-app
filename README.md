# Rhythms

An alternative habit tracker. If you've ever wondered *"when was the last time I …?"* — watered the plants, called mom, cleaned your desk — Rhythms answers at a glance.

**Live app:** https://zednicek-adam.github.io/Rhythms-app/

## How it works

Instead of streaks and checklists, each habit centers on one number: **how many days ago you last did it**. Set an optional target interval (e.g. every 3 days) and Rhythms tells you whether you're on track, due today, or overdue.

## Main features

- **Days-ago counters** — big, glanceable elapsed-day display per habit
- **Target intervals** — optional repeat rhythm per habit with due/overdue states
- **One-tap done** — mark complete today, tap again to undo (with Undo toast)
- **Flexible history** — backdate completions, view and edit the full log
- **Find things fast** — search, status filters (pending / overdue / done), and sorting
- **Two views** — cards or a compact table, both fully functional on mobile
- **Your data stays yours** — everything lives in the browser; JSON export/import backup included
- **Installable & offline** — works as a PWA, including Add to Home Screen on iPhone
